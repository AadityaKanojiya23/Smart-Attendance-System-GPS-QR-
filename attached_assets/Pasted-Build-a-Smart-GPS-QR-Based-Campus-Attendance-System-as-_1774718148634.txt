Build a Smart GPS + QR Based Campus Attendance System as an Expo React Native app (using the Expo + Express TypeScript stack). The app must work on iOS, Android, and Web.

TECH STACK

Frontend: Expo SDK 54, Expo Router (file-based routing), React Native, TypeScript
Backend: Express.js with TypeScript, express-session, bcryptjs
State: React Query (@tanstack/react-query) for server state, React Context for auth
UI: Inter font (@expo-google-fonts/inter), @expo/vector-icons (Ionicons), expo-linear-gradient, expo-blur
QR Display: react-native-qrcode-svg
QR Scanning: expo-camera (CameraView, useCameraPermissions)
Location: expo-location
Haptics: expo-haptics
Tabs: NativeTabs from expo-router (iOS 26+ liquid glass), with BlurView fallback for older iOS/Android
Storage: In-memory (no database needed), pre-seeded demo accounts

BACKEND API (Express on port 5000)

Routes:

POST /api/auth/login — email + password → set session cookie, return user object
POST /api/auth/logout — destroy session
GET /api/auth/me — return current session user or 401
GET /api/users — admin only, return all users
POST /api/sessions — teacher only, create attendance session with { teacherId, className, latitude, longitude, qrToken, expiresAt }
GET /api/sessions/active — return non-expired sessions
GET /api/sessions/my — teacher only, return sessions by logged-in teacher
POST /api/attendance — student only, mark attendance with { qrToken, latitude, longitude }. Validate: session exists, not expired, student class matches session class, student within 100m of teacher GPS, not already marked. Return error message for each failure case.
GET /api/attendance/my — student only, return own attendance records
GET /api/attendance — admin only, return all records
GET /api/sessions/:id/attendance — teacher/admin, return attendance for a specific session

    index.tsx              ← Admin dashboard: stats cards (total students, teachers, sessions, attendance rate)

    _layout.tsx            ← Teacher tab layout (2 tabs: Dashboard, Session)
    index.tsx              ← Teacher dashboard: active sessions, recent attendance counts

  (student)/
    _layout.tsx            ← Student tab layout (2 tabs: Dashboard, Scan QR)
    index.tsx              ← Student dashboard: attendance history list
    scan.tsx               ← QR scanner with full flow
GPS GATE SCREEN (app/(tabs)/index.tsx)

On mount, call expo-location to get current position
Calculate distance from campus using Haversine formula
If within 300m → allow through (navigate to /login or role dashboard if already logged in)
If outside 300m → show "You are outside campus" error with distance info
Always show a "Demo Mode (skip GPS)" button that bypasses the check — for testing when not physically on campus
Show a pulsing location icon, campus name, and real-time distance display
LOGIN SCREEN (app/login.tsx)

Email + password fields with Inter font styling
Navy gradient header with school icon
On success: navigate by role → admin goes to /(admin)/, teacher goes to /(teacher)/, student goes to /(student)/
Show error message if login fails
AUTH CONTEXT (contexts/AuthContext.tsx)

Wraps app with session-based auth
login(email, password) → POST /api/auth/login → set user, navigate by role
logout() → POST /api/auth/logout → clear user, navigate to /login
refetch() → GET /api/auth/me → restore session on app reload
Check session on mount; show loading spinner while checking
TEACHER SESSION SCREEN

Button: "Start Attendance Session"
On press: get GPS location → generate QR token (timestamp + random string) → POST /api/sessions with GPS coords, className, expiresAt = now + 60s
Show animated QR code (react-native-qrcode-svg) with 60s countdown timer (Animated progress ring)
QR pulses with scale animation
After 60s: show "Session Expired" state, offer to start new session
QR token format: SESSION_<teacherId>_<timestamp>_<random>
STUDENT SCAN SCREEN

Idle state: show requirements card (100m proximity, 60s window, class match), "Open Scanner" button
Scanning state: CameraView fullscreen with overlay, corner-bracket frame, pulsing animation
On scan:
Check if this QR token was already scanned locally → if yes, show "Already Marked" screen for 2.5s → auto-return to scanner
If new token: get GPS → POST /api/attendance
On success: add token to local Set (prevent re-scans), show "Attendance Marked!" for 2.5s → auto-return to scanner
On error: show error screen with "Try Again" and "Go Back" buttons
Web fallback: camera not available message
Haptics: Success/Warning/Error feedback
ADMIN SCREENS

Dashboard: 4 stat cards — Total Students, Total Teachers, Total Sessions, Attendance Rate (%)
Students tab: FlatList of all students with role badge
Teachers tab: FlatList of all teachers with role badge
Reports tab: FlatList of all attendance records with student name, session info, timestamp

Admin tabs: Home (grid), Students (people), Teachers (school), Reports (bar-chart)

Student tabs: Home (home), Scan QR (scan)

IMPORTANT RULES

Never use UUID package — generate IDs with Date.now().toString() + Math.random().toString(36).substr(2, 9)
Never hardcode domain URLs — use getApiUrl() from @/lib/query-client
All queries use the default fetcher from @/lib/query-client, no custom queryFn
All mutations use apiRequest from @/lib/query-client
Session secret in environment variable SESSION_SECRET
Backend port: 5000, Frontend port: 8081
