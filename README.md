# Smart Attendance System

An Android attendance app distributed as an APK for preview.

## Download the app

Scan this QR code with your phone camera to download the APK:

![QR code to download the Smart Attendance System APK](artifacts/mobile/apk-download-qr.png)

Or open the [direct APK download link](https://expo.dev/artifacts/eas/ezcFZ3jCpuPdnOifgovEl8fsxDW31MmS7rupnNPMyFQ.apk) on your Android phone.

After downloading, open the APK and follow Android's install prompts. The app's online features require an internet connection.
